# AWS Config Resource Monitoring & Compliance Management

## Overview
This project demonstrates the implementation of AWS Config for continuous resource discovery, configuration tracking, compliance auditing, and infrastructure governance within an AWS environment.

AWS Config enables centralized visibility into AWS resource configurations, tracks configuration changes over time, and helps enforce operational and security best practices across cloud infrastructure.

---

## Objectives

- Enable AWS Config for resource inventory management
- Monitor AWS resource configuration changes
- Configure compliance tracking and governance
- Implement centralized configuration recording
- Explore AWS Config rules and auditing capabilities
- Understand cloud governance and operational monitoring

---

## Key Concepts Explored

### Configuration Monitoring
AWS Config continuously records and evaluates AWS resource configurations to maintain visibility and compliance across infrastructure.

### Compliance Auditing
The service enables organizations to evaluate resources against predefined governance and security rules.

### Change Tracking
Tracks configuration modifications, resource relationships, and infrastructure history over time.

### Governance Automation
Supports automated monitoring, compliance reporting, and operational troubleshooting.

## Implementation Workflow

1. Enabled AWS Config service

3. Set up delivery channels using Amazon S3
4. Explored AWS managed compliance rules

The implementation follows a centralized cloud governance workflow:
